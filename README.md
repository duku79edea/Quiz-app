# React Quiz Application

## Project Description

This project is a responsive multiple-choice Quiz Application built with React.

The application allows users to answer quiz questions, navigate between questions, view their selected answers, see the correct answers and explanations, and receive their final score after completing the quiz.

The interface is designed to work on both desktop and mobile screen sizes while following the provided reference design as closely as reasonably possible.

## Features

* Multiple-choice quiz questions
* Question number and current question display
* Selectable answer options
* Next and Previous navigation
* Direct navigation between questions
* Question navigation panel
* Visual indication of:

  * Current question
  * Answered questions
  * Unanswered questions
* Correct answer indication
* Explanation for each question
* Answers are saved when navigating between questions
* Final score displayed after completing the quiz
* Responsive design for desktop and mobile devices
* No unnecessary page reloads during quiz navigation

### How to Run the Project Locally
Follow the steps below to set up and run the Quiz Application on your local development environment.

### Prerequisites
Before getting started, make sure you have the following installed:

* **Node.js** (LTS version recommended)
* **npm** (included with Node.js)
* **Git**

You can verify your installations by running:
node --version
npm --version
git --version

### 1. Clone the Repository
Clone the project repository from GitHub:
git clone https://github.com/duku79edea/Quiz-app.git

### 2. Navigate to the Project Directory
Move into the cloned project directory:
cd Quiz-app

### 3. Install Dependencies
Install all required project dependencies using npm:
npm install

### 4. Start the Development Server
Start the Vite development server:
npm run dev

Once the server starts successfully, the terminal will display a local development URL similar to:
http://localhost:5173/

Open the URL in your preferred web browser to access the application.

### 5. Build the Application for Production
To create an optimized production build, run:
npm run build

The production-ready files will be generated in the `dist` directory.

### 6. Preview the Production Build
To preview the production build locally, run:
npm run preview
